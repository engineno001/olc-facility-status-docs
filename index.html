2. 状態遷移

状態遷移は、次の3つのルールに基づいています。

  1. すべてのステータスは「編集可」から始まり、「編集可」に戻ります。
  2. 撮影と点検は直接切り替えできません。一度終了して「編集可」に戻してから、もう一方を開始します。
  3. オンラインは複数端末で共有、オフラインはダウンロードした端末のみが操作できます。

3. ステータスごとの操作可否

「ほかの端末」とは、施設を現在のステータスにした端末以外の端末を指します。

まとめ
  • Web で編集できるのは「編集可」のときのみです。それ以外のステータスでは、Web は閲覧のみとなります。
  • オンラインは共有：同じ種類の端末であれば複数台で同時に作業できます。オフラインは専有：ダウンロードした端末のみ操作できます。
  • 同じ施設で撮影と点検を同時に行うことはできません。

4. 各ステータスの詳細フロー

4.1 オンライン撮影 — 撮影中（No.113）

  • 複数台の点検SHOTで同じ施設を同時に撮影できます。
  • 後から同期した端末のデータで上書きされます（Last Update Wins）。
  • 運用ルール：同じフロアを複数端末で撮影しないようにしてください。

4.2 オフライン撮影 — オフライン撮影中（No.133）

  • 点検SHOTに次の2つのボタンを設けます。
    • 撮影開始：現行どおり
    • データダウンロード：新規
  • ダウンロードが成功すると、ステータスが自動で「オフライン撮影中」に切り替わります。ダウンロード後にほかの端末からデータが変更されないようにするためです。
  • 操作できるのはダウンロードした端末のみです。ほかの端末と Web は閲覧のみとなります。
  • ダウンロードのみで撮影しなかった場合は、詳細画面で「撮影終了」を手動でタップして「編集可」に戻します。
  • データダウンロードは「編集可」のときのみ可能です。撮影中（オンライン撮影中）の施設ではダウンロードできません。

4.3 オンライン点検 — 点検中（No.102、113）

  • 「点検を開始する」モーダルで「オンライン点検」を選択します。
  • 複数台の iPad で同時に点検でき、結果はリアルタイムで共有されます（現行どおり）。
  • 点検アプリの画面は自動更新されないため、「リロード」ボタンを追加し、最新データを取得できるようにします。
  • Web は閲覧のみとなります。
  • 点検中はオフライン点検を開始できず、点検SHOTでも施設を選択できません。

5. 運用上の注意点

上記の仕様を実現するにあたり、以下の点にご留意ください。

#項目内容
1Web の閲覧のみ制御「編集可」以外のステータスでは、Web からのすべての編集操作（ポイント・フロア・フォルダ・ファイル・図形・施設情報）を不可とし、制御を統一します。
2Web 画面のステータス表示Web 画面はステータスを自動更新しません。「編集可」で画面を開いた後にアプリ側で撮影・点検が開始された場合、編集ボタンが表示されたままになることがありますが、保存時にサーバー側で拒否し、エラーメッセージを表示します。
3同時操作2台の端末で同時に撮影開始・ダウンロード等を行った場合、先に処理された1台のみ成功し、もう1台はエラーとなります。
4撮影中の「撮影終了」撮影中はどの端末からでも「撮影終了」できます。ほかの端末に未同期データが残っている場合、その端末の同期はエラーになるため、「撮影終了」をタップした際に「ほかの端末で撮影中の場合、未同期データが同期できなくなります。終了してよろしいですか？」といった確認メッセージを表示します。
5端末の識別同じアカウントで複数の端末にログインしている場合でも、オフライン撮影・オフライン点検は端末単位で専有を判定します。

以上、ご確認のほどよろしくお願いいたします。
